      Panduan Mengganti Channel Saya (Multi-Channel & Brand Account)
      
        
      
        
      
      
      
      
      
        
      
          💡 Cara Tercepat & Praktis (Tanpa Login Ulang):
      
          Gunakan fitur Instant Switcher di bilah atas tab ini. Anda cukup memasukkan @handle atau URL channel Anda yang lain (misal: @KanalBisnisAnda), lalu klik Ganti Channel. Sistem akan langsung memuat statistik subscriber, total video, total views, membedah rasio format video (Landscape vs Shorts), dan menghitung gap monetisasinya!
        
      

        
      
          
      
            📌 Kasus 1: Satu Akun Gmail dengan Banyak Channel (Brand Accounts)
          
      
          
      YouTube mengizinkan 1 alamat email Gmail memiliki banyak sub-channel (*Brand Accounts*). Jika Anda ingin mengganti otorisasi resmi Google OAuth ke Brand Account lain:
      
          
        
            
      1. Jalankan perintah di terminal lokal: python login_youtube.py
        2. 
            
      2. Browser akan terbuka otomatis. Google akan menampilkan layar: "Pilih akun atau channel untuk melanjutkan ke YouTube Studio".
        3. 
            
      3. Pilih nama Brand Account spesifik yang ingin Anda sambungkan. Token otorisasi akan otomatis diperbarui di file .youtube_token.json.
        4. 
          
      
        
      

        
      
          
      
            📌 Kasus 2: Channel Terdaftar di Akun Gmail yang Berbeda
          
      
          
      Jika channel Anda berada di bawah alamat email Google yang berbeda (misalnya Gmail pribadi vs Gmail kantor):
      
          
        
            
      1. Jalankan script otorisasi: python login_youtube.py
        2. 
            
      2. Pada pop-up Google Login di browser, klik tombol "Gunakan akun lain" (Use another account).
        3. 
            
      3. Masukkan email Gmail kedua dan password Anda, lalu setujui izin YouTube Studio.
        4. 
            
      4. Token baru berhasil dibuat untuk Gmail tersebut.
        5. 
          
      
        
      

        
      
          
      
            🌐 Kasus 3: Di Lingkungan Cloud / Vercel
          
      
          
      Pada hosting cloud (Vercel Serverless), token file OAuth tidak disimpan demi alasan keamanan data pribadi. Anda dapat bebas berganti channel kapan pun menggunakan Instant Switcher tanpa batasan akun Gmail.
